# Pythonの演算子と優先順位

## 1. 算術演算子
計算をするときに使用する演算子。

| 演算子 | 意味 | 例 |
|---|---|---|
| + | 足し算 | 5 + 3 = 8 |
| - | 引き算 | 5 - 3 = 2 |
| * | 掛け算 | 5 * 3 = 15 |
| / | 割り算 | 5 / 2 = 2.5 |
| ** | 累乗 | 2 ** 3 = 8 |
| % | 剰余（余り） | 5 % 2 = 1 |
| // | 整数の割り算 | 5 // 2 = 2 |

## 2. 比較演算子
2つの値を比較して、正しい場合はTrue、間違っている場合はFalseを返す。

| 演算子 | 意味 |
|---|---|
| == | 等しい |
| != | 等しくない |
| > | より大きい |
| < | より小さい |
| >= | 以上 |
| <= | 以下 |

例：`5 > 3` の結果は True になる。

## 3. 論理演算子
複数の条件を組み合わせるときに使う。

| 演算子 | 意味 |
|---|---|
| and | 両方の条件がTrue |
| or | どちらかの条件がTrue |
| not | 条件の結果を反転する |

例：`5 > 3 and 10 > 5` の結果は True になる。

## 4. 演算子の優先順位

Pythonでは、演算子によって計算する順番が決まっている。

主な優先順位は次のとおり。

1. () ：括弧
2. ** ：累乗
3. *、/、//、% ：掛け算・割り算
4. +、- ：足し算・引き算
5. ==、!=、>、<、>=、<= ：比較演算子
6. not ：論理否定
7. and ：論理積
8. or ：論理和

例えば、`2 + 3 * 4` の場合は、掛け算が先に計算されるため、結果は14になる。

## 5. 調べて分かったこと

Pythonには、足し算や掛け算などの基本的な計算だけでなく、値を比較したり、複数の条件を組み合わせたりする演算子があることが分かった。また、演算子には優先順位があり、基本的には優先順位の高いものから計算される。括弧を使うことで、自分の決めた順番で計算できることも分かった。
